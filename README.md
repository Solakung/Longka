# ลงกา · วิถีแห่งกรรม 🪔
โร้กไลก์ 8 บิตธีมรามายณะ เล่นบนเบราว์เซอร์มือถือ ออฟไลน์ 100%

## ระบบในเกม
- ดันเจี้ยนสุ่มใหม่ทุกรอบ ๒๐ ชั้น · บอสทุกชั้น ๕ (พญาขร → มารีศ → กุมภกรรณ → ทศกัณฐ์)
- ๔ อาชีพ: กษัตริย์ / พราหมณ์ / วานร / ฤๅษี · เลเวล-สเตตัส-อาคม ๔ บท
- ร้านค้าวาณิช + **เควสต์ล่าอสูรรับรางวัล** (รับซ้ำได้) · เทวาลัยสวดขอพร · ระบบปุญ/กรรม
- พระดาบสฮีลฟรี · นาคโจมตีระยะไกล · มินิแมป · หมอกสงคราม · เซฟอัตโนมัติ (ตาย = ลบเซฟ)
- ทำเนียบวีรชน · เสียงชิปจูน + เสียงพื้นแทนปูรา · ติดตั้งเป็นแอปออฟไลน์ได้ (PWA)

## เล่นในเครื่อง
python python/serve.py      # เปิด http://127.0.0.1:8000

## ขึ้น GitHub Pages (2 นาที)
1. สร้าง repo ใหม่ → อัปโหลดไฟล์ทั้งหมด (ให้อยู่โครงสร้างเดิม)
2. ที่ repo → **Settings → Pages → Source: Deploy from a branch** → branch `main` โฟลเดอร์ `/ (root)` → Save
3. เปิด `https://<ชื่อคุณ>.github.io/<ชื่อrepo>/` บนมือถือได้เลย
4. แนะนำ: เปิดเว็บใน Chrome/Edge → เมนู → "เพิ่มลงหน้าจอหลัก" เพื่อเล่นออฟไลน์เต็มรูปแบบ
